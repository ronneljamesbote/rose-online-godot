# Not in game yet

Features the original iROSE 129 game had that our game does not have yet. Each page says
how the feature worked in iROSE 129 (from the client data, NPC dialogs and quest scripts),
what our game does instead today, and what building it would take on the server, in the
client and in the data. Facts that could not be checked are marked as open questions.

These pages are specifications. To ask for a feature, open a pull request that changes the
page's `status` from `not-in-game-yet` to `in-game` (and settles its open questions); the
feature is then built in that same pull request, as for any other wiki change. See
[[rules/how-this-wiki-works|How this wiki works]].

Clan features build on [[backlog/clans|Clans]]; the faction wars build on
[[backlog/pvp-teams-and-zone-triggers|PvP teams and zone triggers]].
