# Rules

How the game works: the formulas, timers, limits and rules behind every system. Each page
shows its numbers in the table at the top and explains them below, with worked examples.
The `source` row says which code runs the rule, so a change to a page tells a developer
exactly where to change the game.

[[rules/combat|Combat]], [[rules/stats|Stats]] and [[rules/experience|Experience]].
