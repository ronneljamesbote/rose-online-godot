# First wiki edit

Test the whole wiki process once with a real change: edit a page on GitHub, open a pull
request, and have Claude make the game match in that same pull request (skill
`implement-wiki-change`).

A good first change is an open question that is a plain bug, for example
[Combat](../wiki/rules/combat.md): in player against player fights the hit chance divides by
the attacker's own Avoid, so most attacks between players miss.
