# Build "Not in game yet" features

The pages in [wiki/backlog](../wiki/backlog/index.md) describe iROSE features our game lacks:
clans (grades, skills, marks, house, fields), faction shops and wars, PvP teams, memos, chat
rooms and tabs, item appraisal, item delivery, storage fees and password, time coupons,
tutorial hints and bag weight.

To build one, change its page's `status` to `in-game` in a pull request and settle its open
questions; the feature is built in that same pull request.
